# ボロノイ図インタラクティブ・ジェネラティブアート

クリック操作でサイトを追加・ドラッグ移動できるインタラクティブなボロノイ図アートジェネレーター。

## 機能

- クリックでサイト追加、ドラッグで移動、右クリックで削除（最大 200 サイトを滑らかに描画）
- カラーモード 4 種（パステル / 距離グラジェント / ヒートマップ / 白黒）
- ドロネー三角形オーバーレイと外接円中心の表示切替
- エッジスタイル 3 種（塗りつぶし / 輪郭のみ / 点線）と速度調整付きサイト自律ドリフトアニメーション
- PNG エクスポート、localStorage によるセッション設定の保存
